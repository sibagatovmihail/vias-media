Date: 2026-10-08 · Branch: `redesign/reference-study` · Page: `index.html` · Target: WCAG 2.2 AA

## Automated (axe-core 4.14.0, tags wcag2a/2aa/21a/21aa/22aa + best-practice)

| Configuration | Violations | Passed rules |
|---|---|---|
| 1440×900, light, German | 0 | 46 |
| 1440×900, dark, German | 0 | 46 |
| 390×664, light, German | 0 | 46 |
| 390×664, dark, English | 0 | 46 |

Run with `prefers-reduced-motion: reduce`, so every element is in its final, visible state.
The grain, registration marks and fog layers were removed for the run (decorative, `aria-hidden`).

Found and fixed during the run:

- "Fallstudie ansehen" buttons were light-on-light (1.04:1) in the static project list (reduced motion / no JS).
- Language toggle and project links had `aria-label`s that did not contain their visible text.

axe could not judge three items automatically; checked by hand:

- `.mark` (accent block in the footer headline): #161514 on #E8593A = 5.1:1.
- Footer wordmark: decorative, `aria-hidden`.
- Consent banner body text: ink-2 on ground = 8.4:1 (light), 10:1 (dark).

## Colour contrast of the palette (computed)

| Pair | Light | Dark |
|---|---|---|
| ink on ground | 15.3:1 | 15.4:1 |
| ink-2 (body secondary) on ground | 8.4:1 | 10.0:1 |
| ink-3 (annotations, unfilled statement words) on ground | 5.2:1 | 6.2:1 |
| ink on accent (buttons, mark) | 5.1:1 | 5.1:1 |
| title-block text (78 % media-ink on #121110) | about 10:1 | about 10:1 |

The accent on the page ground is 3.0:1 (light). It is used as a fill behind dark text only, never as text.

## Keyboard

- Skip link appears on first Tab and jumps to `#main`.
- Visible focus ring (2px ink outline) on links, buttons, accordion triggers.
- Tabbing through the project reel brings the focused project on stage.
- Menu sheet: opens/closes with the button, closes with Esc and returns focus; the page behind is `inert`.
- FAQ: buttons with `aria-expanded` / `aria-controls`; one panel open at a time.
- The custom cursor hides and the native one returns on Tab.

## Motion

`prefers-reduced-motion: reduce` switches off: smooth scrolling, the pinned reel (it becomes a plain list of four figures), line reveals, the ink-fill statement, the ticker, and the cursor label lag.
